# Favicon Finder

A Chrome extension that finds all favicons on the current website and lets you download them in one click.

## Features

- Instantly finds every favicon declared on the current page, plus the site's `/favicon.ico`
- Shows a preview, size and format (ICO, PNG, SVG, JPG, GIF, WEBP) for each favicon
- Sorts favicons from smallest to largest
- Copy a favicon's URL, download a single favicon, or download all of them at once

### Setup
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
